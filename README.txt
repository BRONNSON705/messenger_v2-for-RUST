MY MESSENGER — запуск

1. Остановите старые копии сервера My Messenger, если они запущены.
2. В корне проекта выполните:
   cargo run -p my_messenger_server
3. Сервер этой версии слушает http://127.0.0.1:3001
4. Затем запустите клиент:
   cargo run -p my_messenger_client
5. Если клиент был запущен раньше и сохранил старый токен, выйдите из аккаунта и войдите снова.

Причина предыдущего os error 10048:
порт 3000 уже был занят другим процессом/старой копией сервера.
